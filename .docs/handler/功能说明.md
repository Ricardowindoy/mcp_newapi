# handler 功能说明

MCP 工具层 handler 实现（internal/mcp/handler），**薄壳约定**：解析参数 → 调 domains 域函数 → 统一输出。全部 25 个工具的 handler 按档位放四文件（read/ops/admin/report），声明（名字/档位/参数）见 registry 模块的汇总表——本模块不做注册。

## 职责

- **helpers.go**（唯一公共件）：`Handler` 类型签名（mcp-go CallToolRequest → CallToolResult）；`JSONResult`（MarshalIndent 输出 JSON 文本）；`ErrResult`（newapi.APIError → `[reachable=… status=…] message` 工具错误，保留可达性信息）；`orDefault`/`orDefaultStr` 参数兜底
- **read.go**（13 个）：status（附 relay 探测 5s 独立超时）、list_models（附 group_count/model_count 汇总）、list_channels/get_channel、list_tokens、logs（Query 组装）、usage_summary（days 夹取 1..365，按模型聚合+total 汇总+quota_usd）、pricing（RawMessage 透传）、list_options（系统设置键值对，count+options）、success_rate（日志 type=2/5 计数求比率，hours 1-720 或显式时间窗）、**autoban_config（autoban 配置总览：options 按键筛选 + 渠道级 auto_ban 普查 on/off/unset 与未开启清单）、autoban_analysis（封禁原因分析数据：目标=status=3 或带 status_reason 或指定 id，logs.Count 精确总量 + Search 采样，errStats 聚合 + classifyBanCause 启发式；跨域编排放本层——success_rate 同先例）**、jiyuan_report（基元消费报表，report.go）
- **ops.go**（6 个）：test_channel、test_all_channels（附 hint）、update_channel_balance（刷新后回查详情）、set_channel_status（changed+note）、create_token（**只回掩码 key**）、delete_token（confirm 强制）
- **admin.go**（6 个）：create_channel（type/key/models 必填校验）、update_channel（PATCH 收集非空字段；auto_ban/tag 布尔三态按「是否出现」收集）、delete_channel（confirm 强制）、update_option（key/value/confirm 必填，系统设置全局生效）、autoban_codes（状态码增删查改，action=list|add|remove|set）、tag_channels（按标签批量 edit/enable/disable）
- **report.go**（1 个）：jiyuan_report——调 reporter.Store 聚合从库；**rep 为 nil（未配置 [report]）时工具仍注册、调用即报「报表功能未配置」错误**（配置不足必须显式报告给调用方，不静默降级）

## 输出与安全约定

- 全部输出 JSON 文本（`JSONResult`）；错误走 `ErrResult`（业务可达性保留在错误文本里，Agent 可区分网关挂了/业务错）
- **渠道测试不通是有效结果**：返回 success:false 的正常 JSON，不是 error
- create_token 响应：id + key_masked + note（完整 key 去面板看）；无额度入参自动 unlimited（避免 0 额度不可用令牌）
- delete_token / delete_channel：confirm≠true 直接拒绝；id≤0 / name 空 / 必填缺 → 参数级错误
- 完整 key 只在创建/更新请求中传输（调用方显式传入），任何响应不回显

## 边界

- 不做业务判断与上游请求拼装（domains 的事）；输入校验（必填/id>0/confirm/长度）除外
- 不直接 import 域包以外的上游细节；引用 client 根包仅限共享件（Client/APIError/QuotaPerUnit）
- 更新渠道时**不收集 status**（启停走 set_channel_status）——handler 层字段白名单已排除
