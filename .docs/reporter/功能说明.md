# reporter 功能说明

报表域（internal/reporter）：**直连报表从库（MySQL）**，聚合基元渠道调用量与消费。与 newapi HTTP 域不同源——数据来自本地从库（newapi.logs + 自定义 model_price_snapshots 表），不走 client 传输层，是独立叶子包（uses 为空），仅被 handler/registry 引用。凭据经 config 的 db_dsn_file 间接注入（本包不读配置）。

## 职责

- `Open(dsn)`：`sql.Open("mysql", dsn)` 惰性建连；dsn 为空返回 nil Store（工具仍注册、调用时报配置不足错误——**配置不足必须显式报告调用方，不做静默降级**）
- `(*Store).JiyuanReport(ctx, nameLike, days)`：三条 SQL（渠道×模型聚合 / 价格快照 / 每日趋势）→ `BuildReport` 纯聚合 → 结构化 Report
- `BuildReport(details, prices, daily, ...)`：**纯函数**（可独立单测）——消费 = (Prompt−缓存)/1M×输入价 + 缓存/1M×缓存价 + Completion/1M×输出价；tokens 只计成功请求(type=2)；价格按计费模型（other.upstream_model_name 回退 model_name）取最近快照，缺价按 0 并记入 MissingPrices

## 边界

- SQL 语义与参考实现（hermes 侧 python 脚本）一致，但为 Go 原生实现，不 exec 外部脚本
- 不产出 markdown 文件——返回结构化 JSON，渲染交给调用方
- 不感知 HTTP/MCP；连接失败/查询失败都作为错误上抛给调用方
