# entry 功能说明

程序入口（cmd/newapi-mcp/main.go）：把配置、传输客户端、MCP server 三者装配起来并以 stdio 传输启动服务。

## 职责

- `flag.String("config", …)` 解析 `--config <path>`（缺省只用默认值+环境变量）
- `config.Load(path)` 装载配置；失败 → stderr「配置错误: …」+ exit 1
- `newapi.NewClient(baseURL, token, timeout)` 构造传输客户端（TimeoutSec 秒转 Duration）
- `mcp.NewServer(client, writemode)` 装配 MCP server（注册表在 registry 模块）
- `server.NewStdioServer(s)` + `SetErrorLogger(log.New(os.Stderr…))` + `Listen(ctx, stdin, stdout)` 启动；退出 → stderr + exit 1

## 边界

- **零业务逻辑、零工具实现**：本文件只有装配与启动，所有能力来自 config/registry/client 模块
- **stdout 是 JSON-RPC 专线**：任何日志/打印都不得写 stdout（会污染 stdio 协议流）；错误与日志只走 stderr
- 退出码约定：配置错误 1、server 异常退出 1；正常无退出路径（长驻进程）
- DSH 生产以 `~/.dsh/mcp-newapi-wrapper.sh` 拉起本二进制（--config ~/.dsh/newapi-mcp.toml），改 wrapper 或二进制后需重启 DSH 生效
