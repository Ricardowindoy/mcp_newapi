## 执行序列

```go
configPath := flag.String("config", "", "TOML 配置文件路径（缺省只用默认值+环境变量）")
cfg := config.Load(*configPath)                  // 失败: stderr + os.Exit(1)
client := newapi.NewClient(                      // BaseURL/Token/TimeoutSec*Second
    cfg.NewAPI.BaseURL, cfg.NewAPI.Token,
    time.Duration(cfg.NewAPI.TimeoutSec)*time.Second)
rep := reporter.Open(cfg.ReportDSN())            // 报表从库；DSN 未配置 → nil Store
s := mcp.NewServer(client, cfg.NewAPI.WriteMode, rep) // registry 模块：表驱动注册
stdioServer := server.NewStdioServer(s)
stdioServer.SetErrorLogger(log.New(os.Stderr, "", log.LstdFlags))
stdioServer.Listen(context.Background(), bufio.NewReader(os.Stdin), os.Stdout)
```

## 关键点

- **依赖注入链**：config 产出值 → client 持有连接参数、reporter.Store 持有报表从库 → NewServer 把两者闭包注入每个 handler 工厂（registry 模块的表项 Handler 调用点）。任何一环签名变化都从 main 开始连锁改
- **报表 DSN 缺席不阻断启动**：cfg.ReportDSN() 为空 → rep=nil → jiyuan_report 工具仍注册、调用时报「报表功能未配置」（配置不足显式报告调用方）
- **Listen 参数**：ctx 用 Background（进程生命周期即 ctx）；stdin 经 bufio 包装，stdout 裸 os.Stdout
- **错误日志**：mcp-go 的 SetErrorLogger 接 stdio 协议错误之外的服务级错误，落 stderr 带时间戳
- 构建产物：`go build -o bin/newapi-mcp ./cmd/newapi-mcp`（bin/ 已 gitignore）

## 修改注意

- 本文件保持 45 行级别的「薄」：加能力先想清楚该落在 config（配置）/ registry（工具）/ client（传输），而不是 entry
- 若新增 flag（如 --version / --http），同步更新 README 快速开始与 .docs/entry
