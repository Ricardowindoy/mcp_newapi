## 各域实现要点

### status

- `Data` 裁剪自 /api/status 的 data（上游字段多，json.Unmarshal 忽略多余字段）
- `RelayProbe`：GET /v1/models；出错时若 APIError.Reachable=true（含 401/403）→ 返回 nil（relay 活着）；Reachable=false 才上抛。**探测语义依赖 client 的错误分类，改 APIError 需回归此处**

### models

- `List` 返回 map[string][]string（分组→模型名），每组 sort.Strings 后原 map 返回
- `Pricing` 原始 data（json.RawMessage）透传，handler 再包 json.RawMessage 输出

### channels

- raw 含 `OtherInfo`（上游塞 JSON 字符串的字段）；toSummary 里二次 Unmarshal 抠 `status_reason`
- `List(ctx, c, page, pageSize, status)`：`p` 页码（Itoa 兜 1）、page_size>0 才发、status>0 才发（0=全部）
- `Test` 走 `DoTopLevel`：从顶层 map 抠 success/message/time/error_code；TestResult.TimeSec=float64 秒
- `SetStatus`：POST RouteChannelStatus，body `{"status":1|2}`；上游 data 是 bool 字面量，`string(data)=="true"` 判 changed
- `Create`：POST body `{"mode":"single","channel":UpsertReq}`；成功后 `List(1,100,0)` 按名匹配回查——回查失败包装为「渠道已创建，但回查失败」错误（创建可能已生效，调用方勿重试创建）；找不到名字返回仅含 Name/Type/Status 的兜底 Summary
- `UpdateFields`：body = {"id":id} + fields 逐项；**调用方（handler）负责只收非空字段**；域函数不传 status/只读字段
- `EditByTag`：PUT RouteChannelTag body TagReq（上游 ChannelTag 裁剪版：tag 必填，new_tag/priority/weight/model_mapping/models/groups 指针 nil=不改；不含 param_override/header_override 敏感项）；返回上游 data 原样透传
- `SetTagStatus`：POST RouteChannelTagEnable/Disable body {"tag":tag}

### tokens

- Summary 与 raw 字段同形，toSummary 防御性再掩码（上游本就回掩码）
- `Create`：POST CreateReq → RouteTokenSearch（keyword=名称, p=1, page_size=10）按名回查；回查失败包装「令牌已创建，但查询失败」
- `CreateReq.RemainQuota` int64 quota 单位；ExpiredTime -1=永不过期；ModelLimitsEnabled 由 handler 按是否传了 model_limits 推导

### logs

- `Query` 零值字段不发送（Type=0 不带 type 参数）
- `Search` 直接复用 Paged[Entry]（Entry 即裁剪 DTO，无 raw 二段）
- `Count`：Search 的 page_size=1 包装，只取 Total——成功率查询按 type=2/5 各计一次
- `AggregateByModel`：GET RouteData（start_timestamp/end_timestamp/default_time=custom）→ []point（model_name/token_used/count/quota）→ map 聚合 → quota_usd=quota/QuotaPerUnit → sortByQuota 降序

### options

- `List`：GET RouteOptions → data 数组 [{key,value}]，`sort.Slice` 按 key 排序保证输出稳定
- `Update`：PUT RouteOptions body `{"key":key,"value":value}`（字符串形态；上游 controller 统一 `Interface2String` 落库）；上游 success:false 走 Do 的业务错误路径
- 敏感键由**上游**过滤（后缀 Token/Secret/Key/secret/api_key），本域不做二次过滤但也不解包细字段——整个 data 数组就是裁剪 DTO
- `StatusCodesList/Modify`（statuscodes.go）：**本地镜像上游 status_code_ranges.go 的区间代数**——token 语法单码/闭区间（全角逗号归一，范围 [100,599]，start>end 报错）、解析后按 Start 排序并合并相邻（r.Start<=last.End+1）与重叠区间、序列化单码直出/区间 "a-b"；target 映射 disable→AutomaticDisableStatusCodes、retry→AutomaticRetryStatusCodes。add=并集（已覆盖项进 already_covered）、remove=区间减法（未覆盖项进 not_found）、set=全量重写规范形；先 rawOptionValue 取现值（键不存在视为空）→ 本地算 → Update 写回。上游匹配依赖有序区间，**任何手改乱序串都会静默失效**——本代数保证产出规范形

## 上游契约注释约定

每个域文件顶部注释标明上游来源（如 `controller/token.go`）与请求/响应形态。上游版本漂移时：先查 `.upstream/` 参考快照核对 → 只改本域 DTO/函数 + routes.go 常量。

- logs/logs_test.go：TestCount（page_size=1 + type 透传 + total 解析）
- 新增域函数：至少覆盖「正常 + 业务错误 + 上游形态特例（顶层字段/不回 id）」；不碰真实网关

## 修改注意

- 新 DTO 字段：raw 加字段 → toSummary 搬运（涉密钥过 MaskKey）→ Summary 加 json tag；对上游字段名勿凭记忆，对照快照
- 「按名回查」是 100 条窗口：同名超量场景兜底返回，不报错
- logs.Entry 直接当分页 Items 泛型，没有独立 raw——改字段名要同时核对上游 JSON tag
